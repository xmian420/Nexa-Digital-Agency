# Nexa Digital Studio

Premium Digital Marketing & Web Development Agency website.

## Tech Stack

- React 19 + Vite
- React Router DOM
- SCSS Modules
- Three.js + React Three Fiber + Drei
- Framer Motion
- GSAP
- React Icons
- Lenis Smooth Scroll

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── components/
│   ├── common/       # Loader, Cursor, PageTransition
│   ├── layout/       # Navbar, Footer
│   ├── home/         # Home page sections
│   ├── three/        # 3D components
│   └── ui/
├── pages/            # Home, Services, Portfolio, Contact
├── hooks/            # Custom hooks
├── styles/           # Global styles
└── App.jsx
```

## Features

- Dark futuristic design
- 3D laptop & Earth scenes
- Smooth scrolling (Lenis)
- Page transitions
- Animated counters
- Glassmorphism UI
- Fully responsive
- Code splitting & lazy loading
